# 주정뱅이 집 보내기 (Drunk Journey Home)

가우시안 난수 기반 이동 모델과 RNN 위험 예측을 활용한 2D 귀가 시뮬레이션 게임

## 1. 프로젝트 소개

본 프로젝트는 소프트웨어랩 Term Project로 개발한 2D 귀가 시뮬레이션 게임이다.

사용자는 술에 취한 캐릭터를 조작하여 복잡한 골목길을 통과하고, 다양한 위험 요소를 피해 안전하게 집으로 귀가해야 한다.

일반적인 게임과 달리 가우시안 난수와 사인파를 활용하여 사용자가 입력한 방향과 캐릭터의 실제 이동 방향에 차이가 발생하도록 구현하였다. 또한 이동 속력과 가속도에 따라 메스꺼움과 체력이 변화하며, 구토, 넘어짐, 수면 등의 상황이 발생한다.

RNN(Recurrent Neural Network)을 활용하여 캐릭터의 최근 상태 정보를 분석하고 향후 1초 이내에 발생할 수 있는 위험을 예측하는 기능을 추가하였다.

수업에서 학습한 수학적 개념과 인공지능 알고리즘을 하나의 게임에 통합하고, 데이터 생성부터 모델 학습, 성능 평가 및 실제 게임 적용까지 구현하는 것을 목표로 하였다.

## 3. 설치 및 실행 방법

### 3.1 Visual Studio 설치

Visual Studio 2022를 설치한다.

설치 과정에서 'C++를 사용한 데스크톱 개발' 워크로드를 선택한다.

### 3.2 vcpkg 설치

Git이 설치된 상태에서 Windows 명령 프롬프트(CMD)를 실행한 후 다음 명령어를 순서대로 입력한다.

```
cd %USERPROFILE%
git clone https://github.com/microsoft/vcpkg.git
cd vcpkg
bootstrap-vcpkg.bat
```

### 3.3 raylib 설치

vcpkg 폴더에서 다음 명령어를 실행한다.

```
vcpkg install raylib:x64-windows
vcpkg integrate install
```

이를 통해 Visual Studio에서 raylib 라이브러리를 사용할 수 있도록 설정한다.

### 3.4 프로젝트 실행

1. Visual Studio 2022에서 새로운 C++ 콘솔 앱 프로젝트를 생성한다.
2. src/main.cpp 파일의 내용을 프로젝트의 C++ 소스파일에 복사한다.
3. 프로젝트 속성에서 C++ 언어 표준을 ISO C++17(/std:c++17)로 설정한다.
4. 솔루션 플랫폼을 x64로 설정한다.
5. 솔루션 구성을 Release 또는 Debug로 설정한다.
6. Ctrl + F5를 눌러 프로그램을 실행한다.

한글 주석과 문자열이 깨지는 경우 소스코드의 인코딩을 UTF-8로 설정한다.

RNN 학습 시에는 연산 속도를 고려하여 Release / x64 환경에서 실행하는 것을 권장한다.

### 3.5 RNN 학습 및 적용

학습된 모델이 없는 경우 다음과 같은 과정을 진행한다.

1. 게임을 실행한다.
2. 난이도를 선택하기 전 시작 화면에서 T키를 누른다.
3. 게임 창이 종료되면 콘솔에서 자동 시뮬레이션과 RNN 학습이 진행된다.
4. 총 18 Epoch의 학습이 완료될 때까지 기다린다.
5. 콘솔에 'Training complete. See results folder.'가 출력되는 것을 확인한다.
6. 프로그램을 다시 실행한다.
7. 학습된 RNN 모델이 불러와졌는지 확인한다.
8. 난이도를 선택하여 게임을 플레이한다.

학습 과정에서 data 폴더와 results 폴더가 자동으로 생성된다.

학습된 가중치는 results/rnn.txt에 저장되므로 해당 파일이 존재하면 매번 다시 학습할 필요가 없다.

기존 모델을 사용하는 경우 results 폴더를 프로그램의 작업 디렉터리에 배치한다. 프로그램은 상대 경로를 이용하여 모델과 데이터를 읽고 저장한다.

## 5. 주요 기능

### 5.1 취기 기반 캐릭터 이동

- Box-Muller 변환을 이용한 가우시안 난수 생성
- 취기에 비례하는 이동 방향 오차
- 사인파 기반의 주기적인 비틀거림
- 관성을 고려한 속도 및 방향 변화
- 걷기와 달리기 상태 구분

### 5.2 랜덤 미로 생성

- 게임 시작 시 새로운 골목길 생성
- DFS 기반 무작위 미로 생성
- BFS 기반 안전 귀가 경로 확보
- 맨홀 및 막다른 길 배치

### 5.3 캐릭터 상태 변화

- 이동 속력과 가속도에 따른 메스꺼움 증가
- 달리기에 따른 체력 감소
- 휴식에 따른 상태 회복
- 메스꺼움 증가에 따른 구토 발생
- 급격한 방향 전환 시 확률적인 넘어짐 발생
- 일정 시간 동안 움직이지 않으면 수면 상태 전환
- 맨홀 추락 시 게임 종료

### 5.4 취기 시각화

- 취기에 따른 화면 흔들림 및 회전
- 고취기 상태의 화면 흐림 및 복시 효과
- 캐릭터의 얼굴 색상 및 표정 변화
- 구토, 넘어짐, 수면 애니메이션
- 배경과 캐릭터의 렌더링 분리를 통한 가독성 확보

### 5.5 RNN 실시간 위험 예측

최근 약 2초 동안의 캐릭터 상태 데이터를 분석하여 향후 1초 이내의 위험을 예측한다.

예측 대상은 다음과 같다.

- 구토
- 벽 충돌
- 넘어짐
- 맨홀 추락

각 위험의 출력 점수가 설정된 임계값을 넘으면 사용자에게 경고를 표시한다.

### 5.6 결과 데이터 자동 저장

- RNN 학습 데이터 저장
- Epoch별 학습 손실 기록
- 기존 조건 기반 모델과 RNN의 성능 비교
- 실제 게임 플레이 데이터 기록
- 캐릭터 상태 변화 및 이동 경로 그래프 생성

## 7. 핵심 알고리즘

### 7.1 가우시안 난수

Box-Muller 변환을 이용하여 표준정규분포를 따르는 난수를 생성한다.

Z = sqrt(-2 ln U1) × cos(2πU2)

생성한 난수를 캐릭터의 취기에 따라 조절하여 이동 방향에 불규칙한 오차를 발생시킨다.

취기가 높을수록 이동 방향의 오차가 증가하도록 설계하였다.

### 7.2 사인파

사인함수를 활용하여 캐릭터가 좌우로 주기적으로 비틀거리도록 구현하였다.

S(t) = A sin(2πft)

취기에 따라 진폭 A를 조절하여 난이도별 움직임의 차이를 표현하였다.

가우시안 난수에 의한 불규칙한 오차와 사인파에 의한 주기적인 오차를 결합하여 자연스러운 비틀거림을 구현하였다.

### 7.3 수치 미분 및 적분

캐릭터의 가속도는 이전 프레임과 현재 프레임의 속도 차이를 시간 간격으로 나누어 계산한다.

a = |v(t) - v(t-1)| / Δt

캐릭터의 위치는 속도를 시간에 대해 수치적으로 적분하여 갱신한다.

x(t+1) = x(t) + vx × Δt

y(t+1) = y(t) + vy × Δt

계산된 속력과 가속도는 메스꺼움과 넘어짐 발생 조건에도 활용한다.

### 7.4 DFS 및 BFS

DFS를 이용하여 매 게임마다 새로운 미로를 생성한다.

이후 BFS를 이용하여 출발 지점에서 집까지의 경로를 탐색하고, 탐색된 안전 경로를 제외한 위치에 맨홀을 배치한다.

이를 통해 무작위로 생성된 미로에서도 최소 하나의 안전한 귀가 경로가 존재하도록 구현하였다.

## 8. RNN 모델 구조 및 학습

### 8.1 입력 데이터

캐릭터의 상태 정보를 0.1초마다 수집한다.

| 번호 | 입력 특징 |

| 1 | 이동 속력 |
| 2 | 가속도 |
| 3 | 취기 |
| 4 | 메스꺼움 |
| 5 | 체력 |
| 6 | 벽까지의 거리 |
| 7 | 맨홀까지의 거리 |
| 8 | 벽에 접근하는 정도 |
| 9 | 맨홀에 접근하는 정도 |
| 10 | 달리기 여부 |
| 11 | 이동 여부 |
| 12 | 행동 제한 상태 여부 |

최근 20개 시점의 데이터를 하나의 입력 시퀀스로 구성한다.

### 8.2 모델 구조

| 항목 | 설정 |

| 모델 | Vanilla RNN |
| 입력 특징 수 | 12 |
| 입력 시퀀스 길이 | 20 |
| 은닉층 노드 수 | 24 |
| 출력 노드 수 | 4 |
| 은닉층 활성화 함수 | tanh |
| 출력층 활성화 함수 | Sigmoid |
| 손실 함수 | Weighted Binary Cross Entropy |
| 학습 방법 | BPTT |
| 최적화 방법 | SGD |
| 학습률 | 0.008 |
| Epoch | 18 |
| Gradient Clipping | 적용 |

RNN은 이전 시점의 은닉 상태를 현재 시점의 연산에 활용하여 시간적 정보를 처리한다.

마지막 시점의 은닉 상태를 출력층에 전달하여 구토, 벽 충돌, 넘어짐, 맨홀 추락의 네 가지 위험 점수를 계산한다.

여러 위험이 독립적으로 발생할 수 있으므로 출력층에는 Sigmoid 활성화 함수를 사용하였다.

### 8.3 데이터 생성

외부 데이터셋을 사용하지 않고 게임 내부의 자동 시뮬레이션을 통해 학습 데이터를 생성하였다.

| 데이터 구분 | 시뮬레이션 횟수 |

| 학습 데이터 | 120회 |
| 검증 데이터 | 30회 |
| 시험 데이터 | 40회 |
| 합계 | 190회 |

다양한 이동 상황과 위험 발생 상황을 시뮬레이션하고 캐릭터의 상태 정보와 실제 위험 발생 여부를 기록하였다.

학습 데이터는 모델의 가중치 갱신에 사용하고, 검증 데이터는 모델 및 경고 임계값 선정에 사용하였다. 시험 데이터는 최종적인 예측 성능 평가에 활용하였다.

## 9. 실험 결과

### 9.1 RNN 학습 손실

RNN 모델을 총 18 Epoch 동안 학습시킨 결과는 다음과 같다.

| 평가 항목 | 초기 손실 | 최종 손실 | 감소율 |

| Train Loss | 0.364986 | 0.196079 | 46.3% |
| Validation Loss | 0.362205 | 0.206252 | 43.1% |

학습 과정에서 일부 손실값의 증가가 발생하였으나 전체적으로 감소하는 추세를 나타냈다. 학습 손실과 검증 손실이 유사한 경향을 보였으며, 뚜렷한 과적합 현상은 관찰되지 않았다.

### 9.2 기존 조건 기반 모델과 RNN 비교

위험 예측 성능을 평가하기 위해 기존 조건 기반 예측 모델과 RNN 모델의 F1-score를 비교하였다.

| 위험 유형 | Baseline | RNN |

| 구토 | 0.0395 | 0.6711 |
| 벽 충돌 | 0.2840 | 0.7053 |
| 넘어짐 | 0.1149 | 0.0483 |
| 맨홀 추락 | 0.5500 | 0.8687 |
| Macro F1-score | 0.2471 | 0.5734 |

RNN 모델의 Macro F1-score는 기존 조건 기반 모델 대비 약 2.32배 향상되었다.

특히 구토, 벽 충돌, 맨홀 추락의 세 가지 위험에서 예측 성능이 향상되었다.

반면 넘어짐은 발생 빈도가 낮고 확률적으로 발생하도록 구현되어 있어 RNN의 예측 성능이 기존 모델보다 낮게 나타났다.

## 12. 한계점 및 개선 방향

### 12.1 데이터 불균형

위험 유형에 따라 발생 빈도에 차이가 있으며, 특히 넘어짐에 해당하는 학습 데이터가 부족하였다.

향후 위험별 데이터의 추가 확보 및 샘플링 비율 조정을 통해 데이터 불균형을 개선할 수 있다.

### 12.2 시뮬레이션 데이터의 한계

RNN 학습 데이터는 자동 시뮬레이션으로 생성하였으므로 실제 사용자의 조작 패턴과 차이가 발생할 수 있다.

향후 실제 플레이 데이터를 학습에 활용하여 모델의 일반화 성능을 개선할 수 있다.

### 12.3 RNN의 구조적 한계

Vanilla RNN은 장기 의존성 및 기울기 소실 문제를 가질 수 있다.

향후 LSTM 또는 GRU 모델을 구현하여 기존 RNN과 성능을 비교할 수 있다.

### 12.4 실제 플레이 실험의 한계

게임마다 다른 미로가 생성되므로 지도 복잡도와 경로 길이가 실험 결과에 영향을 줄 수 있다.

또한 반복 플레이에 따른 사용자의 숙련도 차이가 발생할 수 있으므로 동일한 난수 시드, 교차 실험 및 추가 참가자를 활용하여 비교 실험의 신뢰도를 높일 수 있다.

### 12.5 물리 모델의 한계

게임의 취기, 메스꺼움, 체력 및 넘어짐 발생 모델은 실제 인체의 생리학적 특성을 기반으로 한 모델이 아니라 게임의 재미와 난이도를 고려하여 설계한 수학적 모델이다.

따라서 본 프로젝트의 위험 예측 결과를 실제 음주자의 위험 예측에 적용할 수 없다.
